# Studio Bimo

Small, open-source things for Minecraft: Java Edition, made in Honduras.

## Projects

| Project                                                   | What it is                                                                                                          |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| [Tally Hopper](https://github.com/studiobimo/tallyhopper) | A mod for Fabric and NeoForge that lets you turn your computer off at night instead of leaving an AFK farm running. |
| [Datapacks](https://github.com/studiobimo/datapacks)      | Small vanilla datapacks. No mods and nothing for players to install: drop a zip into a world and it works.          |

## How we build

- [.github](https://github.com/studiobimo/.github): the reusable workflows, composite actions and pre-commit hooks every repository here calls, so a fix to a check lands everywhere at once.
- [project-template](https://github.com/studiobimo/project-template): the starting point for a new repository, with the dev tooling, conventions and CI wrappers already in place.

Everything is MIT licensed. Issues and pull requests are welcome; each repository's `CONTRIBUTING.md` says how.
